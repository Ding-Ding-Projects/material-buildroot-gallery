# Material Buildroot visual evidence

This gallery presents four reviewed captures of the Material Buildroot desktop application. The captures show real application states and preserve their original pixels. They document setup and a failed preparation path; they do not show a successful image build or boot.

## Evidence status

The four images below were individually inspected before publication. Their original capture dates are recorded in the inventory. The earlier public gallery contains 67 historical images; those images were not copied or newly reviewed for this update. Existing links to that gallery remain available above.

The current evidence is limited to visible application states. It does not establish successful image generation, ISO production, guest boot, LAN reachability, tunnel behavior, persistence, or complete layout coverage.

## Privacy and provenance

The inventory records the project name, displayed application version, visible state, capture time in UTC, image filename, and image SHA-256. It excludes local filesystem paths and information specific to the capture environment.
